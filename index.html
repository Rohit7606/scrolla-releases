What happens when you tap

  1. 1

    Your browser downloads one file

    It ends in .apk, which is how an Android app arrives when it does not come from the Play Store. Chrome will ask whether you meant it.
  2. 2

    Android asks if your browser may install apps

    Once, the first time. Then open the downloaded file and install it. There is no second app to install and no account to make.
  3. 3

    Play Protect may want to scan it. Let it.

    Google checks because Scrolla asks for the accessibility permission — the same one screen-reading malware uses. Choosing Scan lets it verify the file and carry on. If your phone blocks it outright instead of offering a scan, that phone will not install this way; tell whoever sent you this link.
  4. 4

    Android asks you to allow a restricted setting

    Because Scrolla came from outside the Play Store, Android hides the permission it needs to measure anything. Scrolla walks you through the two taps. Nothing works until you do this.
